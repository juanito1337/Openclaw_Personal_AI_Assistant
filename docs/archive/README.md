Releasebeschreibungen. Sie sind keine aktiven Betriebs- oder Entwicklungsvertraege.

- `pre-container/`: fruehere systemd-zentrierte Architektur
- `GIT_REPOSITORY_PRE_M1.md`: alte Repository-Erstanlage
- `SECURITY_PRE_M1.md`: frueheres Sicherheitsmodell
- `MIGRATION_PRE_CONTAINER.md`: native Migration vor dem Containerbetrieb
- `AUDIT_INITIAL_IMPORT.md`: Audit des urspruenglich importierten Workspace-ZIP
- `releases/`: release-spezifische Hotfixnotizen ohne aktuellen Betriebsvertrag

Aktuelle Dokumente beginnen im [Repository-README](../../README.md) und im
[Architekturvertrag](../architecture/README.md).
